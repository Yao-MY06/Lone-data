**关键事实（决定了你的学习方式）：**

1. **资料里既有讲义又有原始课程**，讲义是 `.md` 图文，直接当教材读，**不需要回视频**（符合"概念卡壳回手册定向补"的既定原则）。
2. **原始课程 12 天，你的窗口是 4 天。** 讲义 day01–day12 覆盖全部业务，4 天不可能按课程节奏走完。
3. **有几节对"后端练手"价值极低，可以硬砍**：day11 ECharts 统计报表、day12 POI 导出 Excel（前者是前端图表，后者是 Excel 导出工具库），以及 day06 的微信小程序前端开发。这三块不产生"认证/分层/数据库/状态流转"的能力。
4. **有几节必须过一遍但不用手敲**：day05 Redis、day06 微信登录、day08 微信支付——涉及外部依赖（支付要商户资质、小程序要 appid），只做"读懂 + 跑通能跑的部分"，不追完整实现。
5. **最后一天有完整版代码**（`资料\day12\项目完整版代码\sky-take-out`），**卡壳时的唯一对照物**——但只在明确卡死时看，不要提前翻，否则手敲变成抄。

### 三个必踩的坑（已实测）

1. **`mvn clean compile` 会失败**，报「程序包 com.sky.constant 不存在」。

   原因：多模块工程里，sky-server 依赖 sky-common / sky-pojo，子模块必须先**安装到本地仓库**才能被引用，`compile` 不做这件事。

   **正确命令**：`mvn install -DskipTests`（按依赖顺序编译 + 安装，4 模块全 SUCCESS）。

2. **JDK 版本**：JDK 25 编译 Spring Boot 2.7.3 会报 `Unsupported class file major version`。工程级已配好（`.vscode/settings.json` 里的 `java.jdt.ls.java.home`），VSCode 打开即生效。

3. **端口冲突**：若 8080 被占，或启动日志里 Tomcat 端口不是 8080（说明被环境变量覆盖了），先查 `netstat -ano | findstr :8080` 定位占用进程。

**路径不能含中文——此条已于 2026-10-13 实测推翻**：工程放在 `F:\study\苍穹外卖\sky-take-out\` 下 `mvn install` 四模块 SUCCESS、应用正常启动、接口 200。
**真正要避开的是另一件事**：不要移动/改名一个**正被 IDE 打开**的项目目录 —— IDE 的 Java 语言服务器（JDT LS）会锁住目录，杀掉后会立即重启重建锁，只报 `Device or resource busy`。移动前先在 IDE 里关闭该文件夹。
