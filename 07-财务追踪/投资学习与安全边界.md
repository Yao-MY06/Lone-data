# 投资学习与安全边界

> **定位：投资教育、模拟和数据项目的学习页，不是买卖指令。** 当前 Java 后端仍是唯一 P0；本页不要求开户、跟单或立即投入资金。

## 一、当前背景与底线

- 当前背景：计算机专业学生，用户提供的月度结余约为 1500 元；这个数字只用于学习规划，不代表可投资金额。
- 最大优先级：先提高技能收入、建立应急储备和防骗能力，再讨论投资。
- 前两阶段不开户实盘、不加入荐股或带单群、不跟单、不碰配资、不碰杠杆、不碰期货期权合约、不碰虚拟币合约和不碰外汇杠杆。
- 任何产品、法规、费用、收益或平台信息在真正行动前都要重新查证；本页不承诺收益、胜率或本金安全。

## 二、四阶段路线

### 阶段 1：防骗筑基（约 2 周）

**目标：** 建立“不亏钱比赚钱重要”的底线思维。

学习和产出：

- 识别荐股群、配资、代操盘、虚假平台和高收益承诺；
- 理解复利、年化收益率、波动率、最大回撤、夏普比率；
- 读一本可靠的基础读物，写一页自己的概念卡；
- 形成一张学生常见投资骗局清单。

**阶段门：** 能用自己的话解释每个概念，并能识别至少三种常见骗局；没有任何转账、开户或跟单行为。

### 阶段 2：工具与模拟（约 2 周）

**目标：** 看懂市场工具和报价，不急着投入资金。

学习和产出：

- 区分 A 股、港股、美股、ETF、场外基金、国债和可转债；
- 只使用模拟盘观察现价、涨跌幅、PE、PB、成交量等字段；
- 了解 GDP、CPI、PMI、利率和汇率的含义及可能影响；
- 写一页“市场地图”和一份模拟观察记录。

**阶段门：** 能解释一个模拟标的的报价字段，不把模拟结果当成真实收益能力。

### 阶段 3：系统知识与 Python 数据项目（约 1–2 个月）

学习模块：

- 货币金融基础：利率、汇率、货币政策和金融机构；
- 证券市场基础：股票、债券、衍生品、交易机制与监管；
- 基金基础：基金分类、费率、定投和风险；
- 财报基础：资产负债表、利润表、现金流量表；
- 只学习基础图表和数据含义，不迷信 K 线形态。

技术项目：

1. 用公开且可核验的数据绘制宽基指数历史估值分位图；
2. 选一家熟悉的公司，读取公开年报并提取关键财务指标；
3. 用 Python 回测月投、周投和预先定义的加仓规则，记录数据源、假设、费用和局限。

**阶段门：** 每个项目都有数据来源、代码、结果和局限说明；不把回测结果写成未来承诺。

### 阶段 4：实盘与体系（持续）

只有前三阶段的学习证据完成，并重新检查应急储备、固定支出、风险承受能力和合法合规边界后，才讨论是否小额实践。实践也必须先写“投资说明书”：目标、期限、最大可接受损失、再平衡规则、停止条件和复盘日期。

## 三、候选资金分配原则

“20%备用金 + 70%稳健投资 + 10%高风险投资”只保留为候选原则，不能自动套用到每月 1500 元：

- 备用金比例要先看固定支出和已有储蓄；
- 稳健投资必须核对产品风险、流动性、费用和实际用途；
- 高风险部分可以暂时为 0%，没有必要为了凑比例而投资；
- 任何比例改变都必须记录理由、数据依据和复盘日期。
