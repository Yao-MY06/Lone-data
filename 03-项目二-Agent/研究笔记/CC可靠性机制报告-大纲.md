| 级 | 来源 | 能支撑什么 |

### D3 防护口径（已确认 2026-10-21）

调研文档里"五级"指过两套不同东西，与实施页 §3.3 也不一致，建议拆开：

- **横向：五类可靠性机制 M1–M5**（即 §3.3 的五条）
  M1 轮次/token/墙钟预算；M2 重复调用检测；M3 stall（无信息增量）；M4 压缩/恢复连续失败熔断；M5 声明-证据绑定。
  其中 M1–M4 是**终止/保护类**，M5 是**结论正确性校验类**，不叫"终止防护"。
- **纵向：处置梯度 observe → steer → block → stop**（四档，主要用于 M2，M3 可复用）。
- **弃用"五级终止防护"这一说法**，报告和代码都不用；pi 的"全批同意才终止"属于终止语义，单列在章 8。

## 三、章 3 合规与来源声明——要点

1. **开源对照（pi、gemini-cli、OpenHands、aider、cline）**：许可证允许阅读与引用；逐项登记许可证类型、版本、文件路径；"读机制、不抄代码"。
   - pi 包内带 `sourcesContent` 的 source map，pi 本身是开源项目，读它符合其许可；这件事只说明 **pi** 的情况。
2. **Claude Code**：专有软件。npm 包里带 source map 是发布层面的现象，**不等于授权**，也不能拿"pi 也这样发布"类比——两者许可状态不同。本报告：
   - 不基于从发布包还原的源码，不引用其路径、行号、代码或提示词原文；
   - 对 CC 的论断只来自 E1，或明确标 E3 的第三方公开分析；
   - 须自行核对 Claude Code 的使用条款，把核对结论和日期登记在案（本草案未替你下结论）。
3. 第三方分析（E3）只引用其公开主张，注明作者、版本、日期，不转载大段原文。
4. 不写"未发现下架通知所以没问题"：缺少下架证据不是授权证据。
5. 版权/商标：报告不使用 Anthropic 标识；教育用途声明可以写，但它不替代以上各条。
