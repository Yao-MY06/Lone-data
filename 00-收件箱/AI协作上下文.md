## 项目一：微服务高并发交易平台范围

### 三项承诺

1. 有限微服务拆分：按业务域拆为 `user`、`shop/content`、`trade`，只在真实调用链中引入 Gateway、Nacos、OpenFeign、Sentinel，并说明边界和失败方式。
2. 秒杀链路深化：Redis Lua 资格判断、MQ 异步下单、幂等、失败重试、最终一致性和对账；依据实际需求比较 Redis Stream 与最终选用 MQ。
3. 工程证据：真实压测、慢查询与索引分析、链路追踪、关键指标、错误诊断和 Docker Compose；只记录可复现结果，无数据时标记未知。

### 候选技术池（默认不启用）

- Caffeine + Redis 多级缓存。
- 布隆过滤器。
- Elasticsearch 复杂搜索与高亮。
- Canal + MQ 数据同步。
- XXL-Job 库存预热和异步对账。
- WebSocket/SSE 秒杀结果通知。
- Feed 推拉结合、智能排序和冷热分离。
- ShardingSphere 分库分表和读写分离。
- K8s 部署。
- 智能探店 Agent、多模态点评和 RAG。

候选项只有在承诺范围完成、解决一个已验证问题并写清验收方式后才可启用。

## 项目二：智能故障诊断与自动评测平台范围

### 最小承诺

- Java/Spring Boot 负责诊断调度、Agent Loop、受限指标/日志/链路工具、证据校验和状态服务。
- 至少两个受限诊断工具，以及一个能真实复现的故障注入场景。
- Redis 保存短期任务状态，MySQL 保存长期诊断记录；生命周期、主体隔离和重启读回必须分别验证。
- 实现循环上限、重复调用检测、无进展检测、上下文压缩和证据绑定中的最小可验证切片。
- 打通“故障注入 -> 采集 -> 诊断 -> ground truth 比对 -> 报告”的真实链路；超时、非法参数、工具失败和证据校验失败可观察。

### 候选技术池（默认不启用）

- Elasticsearch 证据检索、PGVector/Milvus 向量检索。
- RocketMQ/Kafka 诊断任务总线、XXL-Job/PowerJob 调度和 DAG 编排。
- K8s 多副本、Spring Cloud Gateway、Sentinel。
- Java Docker 代码沙箱、多租户平台、记忆压缩、WebSocket/SSE 进度推送。
- 更多诊断工具、更多故障场景和多模型横向对比。

这些候选项属于最小诊断评测闭环后的下一版本，不得并行启动。
