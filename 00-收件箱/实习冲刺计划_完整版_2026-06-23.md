## 二、核心项目：智能图书借阅平台

### 2.1 项目定位
**名称**: 智能图书借阅平台（微服务 + AI Agent）
**目标**: 从单体CRUD进化到高并发微服务 + AI Agent，打造简历核心项目
**辨识度**: "Java工程能力 + AI应用能力"双修，2025-2026大厂后端招聘趋势

### 2.2 架构演进路线

```
阶段0 (现在-7.9): 单体SpringBoot + Vue + MySQL [课设MVP]
 ↓
阶段1 (7.14-7.31): 微服务拆分 + Spring Cloud + 分布式基础
 ↓
阶段2 (8.1-8.15): 高并发场景（缓存/限流/异步/分布式锁）
 ↓
阶段3 (8.16-8.20): 分库分表 + 分布式事务 + 链路追踪
 ↓
阶段4 (8.21-8.31): AI Agent 服务（智能借阅助手 / 图书推荐 / 智能客服）
 ↓
阶段5 (后续): 容器化 + 监控 + CI/CD
```

### 2.3 微服务拆分（4个核心服务）

| 服务 | 职责 | 核心表 |
|------|------|--------|
| `library-user-service` | 用户注册、登录、权限、JWT | user, user_role |
| `library-book-service` | 图书元数据、库存、分类 | book, book_category, book_stock |
| `library-borrow-service` | 借阅订单、归还、逾期 | borrow_order, borrow_record |
| `library-agent-service` | AI Agent、RAG知识库、推荐 | chat_session, vector_doc |

### 2.4 高并发核心改造

#### 多级缓存架构
```
用户请求 → Gateway → Caffeine本地缓存(1级) → Redis Cluster(2级) → MySQL
```

#### 分布式锁防超借
- **Redisson 分布式锁**: `RLock` 保证库存扣减原子性
- **Lua 脚本 + Redis 预扣库存**: 先 Redis 扣减，异步落库
- **乐观锁兜底**: MySQL 版本号防止并发更新

#### 异步化（削峰）
- **RocketMQ**: 借阅成功/逾期提醒/预约释放 全部走消息队列
- **延迟消息**: 预约图书到期自动释放

#### 限流熔断
- **Sentinel**: 接口限流（QPS 500）、热点参数限流
- **熔断**: book-service 宕机时，Gateway 快速失败

### 2.5 AI Agent 设计

**场景**: 智能借阅助手
> "帮我找一本深入讲 JVM GC 的书，要库存充足的，直接帮我借了。"

**技术栈**:
- **Spring AI / LangChain4j**: Java 原生 LLM 调用
- **PGVector / Milvus**: 向量数据库
- **RAG**: 检索增强生成
- **Tool Calling**: Agent 调用后端工具
- **ChatMemory**: 多轮对话记忆

### 2.6 简历写法（已确定）

> **智能图书借阅平台（微服务 + AI Agent）**
> - 将单体架构拆分为 4 个微服务，基于 Spring Cloud Gateway + Nacos 构建服务网格，支撑万级 QPS 查询
> - 设计多级缓存（Caffeine + Redis Cluster）+ 布隆过滤器，图书详情接口 RT 从 120ms 降至 3ms，缓存命中率 98%
> - 针对热门图书限量借阅场景，基于 Redisson 分布式锁 + RocketMQ 异步下单，解决高并发库存超卖问题
> - 基于 ShardingSphere 对 borrow_order 表按 user_id 分库分表（16 库 × 256 表），支撑亿级订单数据
> - 引入 **AI Agent 服务**：基于 Spring AI + LangChain4j 构建智能借阅助手，集成 RAG 知识库与 Tool Calling，支持自然语言完成图书检索→库存查询→自动借阅的完整闭环
> - 全链路接入 SkyWalking 分布式追踪，实现接口 P99 延迟监控与告警

## 六、AI辅助学习原则

1. **不要直接复制AI代码**: 让AI生成→自己理解→手敲一遍→修改优化
2. **用AI解释源码**: 看不懂的源码丢给AI，让它用大白话解释
3. **用AI生成八股文**: "请用面试回答的方式解释HashMap原理"
4. **用AI模拟面试**: "你是Java后端面试官，问我SpringBoot相关问题"
5. **用AI调试bug**: 报错信息直接丢给AI，让它分析原因
