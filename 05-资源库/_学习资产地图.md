# 05-资源库：学习资产地图

> **定位**：资源库里那些大部头「用在哪」的唯一索引。按需查阅，**不是日常入口**，也不要求维护。
> 它存在的唯一目的：让你知道"我以前学过这个，在哪，什么时候会再用到"。

## 一、怎么用（三条就够）

1. **遇到具体问题才来查**。比如苍穹分页写不顺 → 看下表找「04 员工管理」。
2. ⭐ = 与当前主线（苍穹 / 黑马）**直接同构**，今天就可能用得上。
3. 没标的在你的主线之外，**不要现在补**，它们静静地有价值。

## 二、一个关键发现：那 8 份笔记不是旧资料

`Kimi-Agent 技术手册/课程实操笔记/` 里那 8 份，做的是「**员工/部门管理系统**」——它和苍穹外卖是**同一套知识体系的平行版本**：同样的 Controller / Service / Mapper 三层、同样的 JWT 登录、同样的 AOP、同样的分页与事务。

所以它们不该是"学完就封存"的东西，而是**苍穹的另一半答案**：苍穹哪里写不顺，这里面大概率有同一件事的另一种讲法。

## 五、防再散的一句话原则

**05 放原文与资料，04 放提炼后的一句话结论。**

查完这张地图、真正解决了一个问题之后，把那个答案按四字段写进 `04-学习笔记/`（一句话理解 / 一个例子 / 一个易错点 / 来源，并链回 05 的原文）。做到这一步，这些资产才算长进你的系统，而不只是躺在硬盘里。
