# 快速捕获

> **用途**：找到好图片、网页、视频、文档时，立刻记一行，不打断当前 P0。每周一批量处理。

## 待处理

格式：`- [ ] 月-日 | 类型 | 一句话：这是什么、想解决什么 | 链接或本地路径`

类型写：图片 / 网页 / 视频 / 文档 / 书 / 课 / 想法

- [ ] 

---

## 每周一怎么处理

| 判断 | 去向 |
|------|------|
| 值得学，但现在不学 | 移入 [[候选池|候选池]]（保留链接或路径） |
| 能直接支持当前项目 | 放进项目资料，并尽快在项目里用 |
| 是单个知识点，可直接消化 | 按 [[知识处理SOP|知识处理 SOP]] 写最小笔记 |
| 需要多资料、多次实验才能搞清 | 在 `04-学习笔记/主题研究/` 新建一个主题 |
| 外部讨论或文章的观点（含 AI 润色稿） | 按 [[外部讨论摄入SOP|外部讨论摄入 SOP]] 处理，润色稿只算素材 |
| 没有明确用途 | 删除 |

处理完的条目直接删掉，不留“已处理”清单。

**容量**：待处理最多 20 条；漏一周不补债，直接按当前最新的处理。
