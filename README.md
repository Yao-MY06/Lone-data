## 现在怎么用

- 每天只打开 [[00-当前状态面板]]。

- SOP / 参考手册只在当前面板或项目明确需要时打开。
- 中断后 5 分钟恢复，不补债。

## 系统定位

这套系统以 PARA 为基础，把临时输入、当前行动、长期责任、知识与资源分开管理。项目用于承载有明确结果的行动，当前状态面板用于决定今天唯一要推进的下一步。

系统只允许 1 个 P0。恢复性活动不计项目，也不考核产出。

## 基本流转

1. 新事项先记进 [[快速捕获]]，不打断当前 P0。
2. 当前状态面板只保留唯一目标、下一步、最低线、停止条件和恢复动作。
3. 完成记录与证据写进 [[进度日志]]，面板和上下文只放链接。
4. 项目文档放在各自项目文件夹（02 或 03）；自己写的笔记放 `04-学习笔记`，外来资料放 `05-资源库`。
5. 完成或终止后移入 `Z-归档`。
