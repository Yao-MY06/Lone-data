## 系统定位

这套系统以 PARA 为基础，把临时输入、当前行动、长期责任、知识与资源分开管理。项目用于承载有明确结果的行动，当前状态面板用于决定今天唯一要推进的下一步。

系统只允许 1 个 P0。恢复性活动不计项目，也不考核产出。

## 文件夹用途

| 文件夹 | 用途 |
| --- | --- |
| `00-收件箱` | 临时捕获想法、通知、链接和待判断事项；当前状态面板也位于此处。 |
| `01-日记与周期` | 进度日志（阶段完成记录与证据，最新在前）与周复盘模板。 |
| `02-项目管理` | 当前 P0 的简报、交付物、验收与项目 SOP。 |
| `03-领域与长期` | 没有明确完成日期、但需要持续维护的责任与方向。 |
| `04-知识笔记` | 经实际使用或验证后值得复用的知识。 |
| `05-资源库` | 工具、模板、公约和按需参考资料。 |
| `07-财务追踪` | 收入、支出及相关定义。 |
| `08-内容源与进度` | 管理书籍、课程、订阅的候选、阅读和观看进度。 |
| `09-主题研究` | 需要多资料或多次实验时使用的临时研究工作区。 |
| `10-健康追踪` | 以 30 秒记录运动、睡眠和体重趋势，用于诊断与调整。 |
| `Z-归档` | 已完成、终止或不再活跃的内容。2026-10-21 精简归档的清单见 `Z-归档/2026-10-系统精简/归档说明.md`。 |

## 基本流转

1. 新事项先进入 `00-收件箱`，不打断当前 P0。
2. 当前状态面板只保留唯一目标、下一步、最低线、停止条件和恢复动作。
3. 需要形成可见交付物时，在 `02-项目管理` 按项目 SOP 轻量立项。
4. 项目实际验证后，把可复用知识放入 `04-知识笔记`，资料与工具放入 `05-资源库`。
5. 项目完成或终止后移入 `Z-归档`。
