# 个人原则、生活节奏与双轨杂学整合设计

日期：2026-07-17  
状态：已实施；当前执行规则以 `2026-07-18-system-consistency-resolution-design.md`、生活系统和当前状态面板为准。  

## 1. 目标

把三条核心原则落到可观察行为，同时把运动、主线学习、马克思主义经典、投资学习和日常恢复整合进个人管理系统：

1. 未来由现在一步一步创造。
2. 真正的快乐更多来自创造，而不是消耗。
3. 任何视频或认知只有落地为行为，才算真正知道。

设计必须保留当前唯一 P0 规则：Java 后端路线仍是当前主线；生活习惯、辅助线和杂学不能制造第二个 P0。周一至周六的计划任务块统一按 9.33 小时（560 分钟）安排。

## 3. 双轨杂学

- 周一、三、五：阅读《实践论》《矛盾论》，每次联系一个真实学习或生活问题，写出一段自己的分析。
- 周二、四、六：投资基础学习，每次用自己的话定义一个概念，并配一个模拟或数据例子。
- 周日：不安排杂学或复盘；已有输出留到周一处理。
- 同时激活的杂学主题最多两个：马克思主义经典、投资基础。

### 3.1 辅助线边界

- LeetCode 使用代码随想录、Hot 100、剑指 Offer；AcWing 不作为当前主线。卡住时可看题解、手写并背诵，48 小时后脱离答案复做。
- 开发工具学习 Git、Linux、Docker 基本指令，可用图形界面辅助。
- 八股使用 JavaGuide 和小林 Coding，JUC/JVM 归入此类，不等待项目后置。
- MySQL/Redis 进阶只在有余力时学习；时间不足先记忆高频结论。
- 正式投递自 2026-09-15 起可占用该槽；此前只做准备或有限投递，且不能挤掉四类核心内容。

投资路线只作为教育和数据实践路线：防骗认知 → 模拟工具 → 证券/基金基础 → Python 数据项目 → 经过重新评估后再决定是否小额实践。20%备用金、70%稳健投资、10%高风险投资暂记为候选原则，不作为当前自动执行比例。

## 4. 三条原则的行为协议

### 4.1 创作优先闸门

每天第一次打开手机或电脑前，先完成运动和主线的最小动作。游戏、短视频和无目的浏览不能出现在第一专注块之前。娱乐不是被永久禁止，而是安排在当天主线最低完成线之后的明确窗口；短视频不作为默认休息方式。

### 4.2 输入到输出闭环

任何视频、文章或认知都必须绑定一个最小输出：

- 编程：运行代码、修复错误、写测试或形成可复现记录。
- 《实践论》《矛盾论》：用理论分析一个真实问题，写一段不抄书的文字。
- 投资学习：写一个自己的定义，完成一个模拟或数据练习；前两阶段不开户跟单、不进荐股群、不碰杠杆。
- 其他输入：没有最小输出就只进入收件箱，不算“学会”，不继续消费同类内容。

### 4.3 消费摩擦与恢复

- 游戏和短视频从手机首页移除，关闭推送，使用固定时段和计时器；不依赖“我今天一定忍住”。
- 专注块期间手机离开桌面；休息优先选择散步、喝水、远眺、冥想或短暂发呆。
- 发生连续刷视频或超时游戏时，不补偿熬夜、不自责；记录触发原因，立刻执行当前任务的 5 分钟恢复动作。

## 5. 高回报事项的分层

不建立 14 项每日打卡，而是分为：

- 每日锚点：运动、10 分钟规划、创造性主线产出、短休息/饮水、睡前 5 分钟复盘、睡前 40 分钟无电子产品。
- 每周锚点：断舍离或打扫、与家人深度交流约两小时、维护重要关系、一次杂学复盘、财务学习记录。
- 长期方向：AI/自动化工具、可变现的 Java 技能、跨学科思考、用钱购买时间、应急储备和稳健财务。
