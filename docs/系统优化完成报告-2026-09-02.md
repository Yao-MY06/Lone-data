### 08-内容源与进度（5 个文件）

```
08-内容源与进度/
├── 定义与使用SOP.md       ✅ 包含流转规则、容量限制、与现有系统协同
├── 活跃订阅.md            ✅ UP主、专栏、Newsletter 订阅管理
```

### 00-收件箱/快速捕获.md（1 个文件）

```
00-收件箱/
└── 快速捕获.md             ✅ 一行一条即时捕获，每周批量路由
```

**核心功能**：
- 刷到好视频/文章/金句时立刻记一行（不打断当前 P0）
- 每周一批量处理，按路由规则分流到对应模块
- 满 20 条或全部处理完后清空

**路由目标**：
- 支持当前项目 → `02-项目管理/[项目名]/参考资料/`
- 系列课程/书籍 → `08-内容源与进度/候选池.md`
- 需要深入研究 → `09-主题研究/[新建文件夹]`
- 可直接消化 → `04-知识笔记/知识处理SOP`
- 无明确用途 → 删除

### 09-主题研究（1 个 SOP + 动态文件夹）

```
09-主题研究/
└── _主题研究SOP.md         ✅ 何时建立、如何推进、如何结束
```

**使用场景**：
- 某个话题需要看 3 篇以上资料
- 需要做 2 次以上实验/代码验证
- 涉及多个概念需要对比整合

**每个主题文件夹包含**：
- `_研究目标.md`：要搞清楚什么、验收标准是什么
- `资料收集.md`：链接、截图、代码片段
- `实验记录.md`：试了什么、结果如何、下一步试什么

**容量限制**：同时进行最多 2 个主题研究，超过 2 周未推进要么集中搞定要么删除

## 四、关键设计原则

### 1. 容量限制（防止收藏癖）

| 模块 | 容量限制 | 超出时的处理 |
|------|---------|-------------|
| 快速捕获 | 最多 20 条 | 满 20 条或全部处理完后清空 |
| 候选池 | 最多 10 个 | 必须完成或删除一个，才能加新的 |
| 阅读中 | 最多 3 本书 | 必须看完一本，才能开新的 |
| 课程进度 | 最多 2 个课程 | 必须看完一个，才能开新的 |
| 主题研究 | 同时最多 2 个 | 超过 2 周未推进要么集中搞定要么删除 |

### 2. 时效规则（防止囤积）

- **快速捕获**：每周批量处理一次
- **候选池**：加入超过 1 个月未开始的，下次检查时直接删除
- **主题研究**：超过 2 周未推进的要么本周集中 1 天搞定，要么承认"现在不需要"并删除

### 3. 保持单 P0 原则

- 所有新模块不制造第二个 P0
- 内容源学习必须服务于当前 Java 主线或已立项项目
- 辅助线和杂学时段可以使用新模块，但不能挤占主线时间

### 4. 强制输出验证

- 所有学习必须留下可验证产出（代码/实验/自己的话重述）
- 没有输出 = 没学会 = 删除这条记录
- 学习完成后提炼成最小笔记，原始资料归档或删除

## 五、与现有系统的协同

### 每日流程（不增加额外负担）

- **早上 10 分钟规划**：在当前状态面板写下今天唯一 P0
- **刷到好内容时**：立刻在快速捕获记一行（不打断 P0）
- **辅助线时段（19:10-19:55）**：可以推进候选池的内容或主题研究
- **杂学时段（19:55-20:55）**：可以推进候选池的内容或主题研究
- **晚上复盘（20:55-21:40）**：顺手记录今天的运动和睡眠（30 秒）

### 每周流程（周日或周一）

- **批量处理快速捕获**：按路由规则分流到对应模块（10-15 分钟）
- **检查候选池**：超过 1 个月未开始的删除（5 分钟）
- **检查主题研究**：超过 2 周未推进的要么集中搞定要么删除（5 分钟）
- **检查重要关系**：看"下次提醒"，到期的本周联系一次（5 分钟）
- **周复盘**：填写候选池开始学习、主题研究完成、重要关系维护的检查项（已纳入模板）

## 七、常见问题

### Q1：新增这么多模块，会不会增加维护负担？

**A**：不会。核心设计原则是"按需使用"：
- **快速捕获**：只在刷到好内容时用（30 秒）
- **内容源与进度**：只在学习时更新进度（30 秒）
- **主题研究**：只在需要深入某个话题时建立（按需）
- **健康追踪**：每天晚上复盘时顺手记一行（30 秒）
- **关系维护**：每周检查一次"下次提醒"（5 分钟）

### Q2：如果某个模块一直不用，怎么办？

**A**：一个月后评估，不用就删除。不要因为"花了时间建立"而强迫自己用。

### Q3：会不会和现有系统冲突？

**A**：不会。新模块是对现有系统的补充，不替代任何现有流程：
- **收件箱**：快速捕获是收件箱的补充（更快、更轻量）
- **知识笔记**：内容源与进度是知识处理 SOP 的前置步骤（管理进度）
- **项目管理**：主题研究是项目管理的补充（临时研究工作区）

### Q4：如果忘记更新进度，怎么办？

**A**：不补债。下次想起来时从当前位置继续，不回填历史数据。
