## 二、核心策略：项目驱动 + AI辅助 + 重点突破

### 2.1 学习原则
1. **不要追求完美掌握**: 基础阶段达到"能看懂、能改、能查文档"即可

3. **项目驱动**: 每学一个技术点，立即在项目中实践
4. **面试导向**: 学习时同步整理八股文，避免学完再补
5. **日常实习门槛**: 比暑期实习低，大三上投递完全可行

## 三、详细时间规划

### 阶段一：期末冲刺期（现在 - 7.13）
**目标**: 完成期末考试，不挂科，同时推进课设和比赛

| 日期 | 重点任务 |

**并行任务**:

- ESP比赛：与队友分工，你负责软件部分或文档

### 阶段二：基础速成期（7.14 - 8.10，约4周）
**目标**: JavaSE + MySQL + SpringBoot基础 + 第一个项目

#### Week 1 (7.14-7.20): JavaSE核心速成
- **学习资源**: 韩顺平Java、尚硅谷JavaSE（挑重点看）
- **重点内容**:
  - 面向对象（封装/继承/多态/抽象类/接口）
  - 集合框架（List/Set/Map，重点ArrayList/HashMap）
  - 异常处理
  - IO流（了解即可）
  - 多线程基础（了解概念，面试常问）
- **学习方式**: 
  - 2倍速看视频，不要敲所有demo
  - 直接看源码+AI解释，理解原理
  - 每天整理3-5个面试题
- **产出**: JavaSE面试题文档

#### Week 2 (7.21-7.27): MySQL + 数据结构入门
- **MySQL学习**:
  - SQL语句（CRUD、聚合、联表查询）
  - 索引原理（B+树，面试重点）
  - 事务ACID、隔离级别
  - 《MySQL必知必会》快速过
- **数据结构**:
  - 数组、链表、栈、队列、树、哈希表
  - 每天2-3道力扣简单题
  - 王卓视频挑重点看（树的遍历、排序）
- **产出**: MySQL面试题文档 + 力扣30题

#### Week 3-4 (7.28-8.10): SpringBoot速成 + 项目实战
- **SpringBoot学习**:
  - 不要先学SSM！直接SpringBoot
  - 尚硅谷/狂神SpringBoot快速入门
  - SpringMVC（Controller/Service/Mapper三层架构）
  - MyBatis-Plus（简化CRUD）
  - 常用注解、配置文件
- **项目实战**: 智能简历生成体（或新做一个）
  - 技术栈: SpringBoot + MySQL + MyBatis-Plus + Thymeleaf/Vue
  - 功能: 简历模板管理、信息填写、PDF生成
  - 要求: 自己部署到服务器，有线上地址
- **产出**: 可运行的项目 + 项目文档

### 阶段三：进阶与面试准备期（8.11 - 8.31，约3周）
**目标**: Redis + 项目优化 + 八股文 + 简历准备

#### Week 5 (8.11-8.17): Redis + 项目优化
- **Redis学习**:

  - 缓存穿透/击穿/雪崩及解决方案（面试重点）
  - SpringBoot整合Redis
- **项目优化**:
  - 给简历项目加缓存
  - 加登录功能（JWT）
  - 完善文档和README

#### Week 6-7 (8.18-8.31): 八股文 + 简历 + 模拟面试
- **八股文整理**:
  - Java基础（集合、多线程、JVM基础）
  - MySQL（索引、事务、优化）
  - Redis（缓存、数据类型、持久化）
  - SpringBoot（自动配置、常用注解、AOP）
  - 项目相关（技术选型、难点、解决方案）
- **简历制作**:
  - 1个项目详细写（智能简历系统）
  - 技术栈清晰，亮点突出
  - 投递渠道：Boss直聘、实习僧、牛客网
- **模拟面试**:

  - 找同学互相面试

## 十、给AI辅助学习的建议

1. **不要直接复制AI代码**: 让AI生成→自己理解→手敲一遍→修改优化
2. **用AI解释源码**: 看不懂的源码丢给AI，让它用大白话解释
3. **用AI生成八股文**: "请用面试回答的方式解释HashMap原理"
4. **用AI模拟面试**: "你是Java后端面试官，问我SpringBoot相关问题"
5. **用AI调试bug**: 报错信息直接丢给AI，让它分析原因
