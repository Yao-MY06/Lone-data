# 晨间日志模板

> **状态：可选参考，默认不启用。** 只有 [[00-当前状态面板|当前状态面板]] 明确安排时才使用；本页不是日常入口，也不能要求打开项目看板。

---
用途：每天早上用3分钟锚定今日唯一目标，清除大脑混沌
更新频率：每日填写
存放位置：`/01-日记与周期/晨间日志/YYYY-MM-晨间日志.md`（或每篇单独文件）
---

## 模板结构

```markdown
## 日期：YYYY-MM-DD 星期X

### 昨晚睡眠：X小时（质量1-5）

### 今日唯一目标（ONE Thing）：

### 下一步行动（Next Action，必须具体）：
- [ ] 

### 今日生活锚点（可选，填写不超过1分钟）
- 运动：□跑步 □无氧 □游泳 □恢复
- 早晨10分钟规划完成：□
- 今日创造性/主线产出：____________
- 今日消费边界（游戏/短视频前的最低完成线）：____________

### 情绪状态（1-10）：

### 昨日复盘（一句话）：

### 💰 今日变现思考（可选，1分钟）：
- 今天做的事离赚钱更近了吗？（是/否/间接）
- 如果有机会线索要跟进，写在这里：____________
```

## 填写说明

| 字段 | 填写要求 | 为什么重要 |
|------|---------|-----------|
| 睡眠时长+质量 | 诚实记录，包括半夜醒来的次数 | 睡眠是一切生产力的基础设施 |
| 今日唯一目标 | **只写一件**，不是三件，不是五件 | 多目标=无目标，你今天只能有一件最重要的事 |
| 下一步行动 | 具体到"打开哪个文件、写哪行代码" | 模糊的行动描述会导致启动阻力 |
| 情绪状态 | 凭直觉打分，不用过度思考 | 长期追踪可发现你的焦虑/动力周期 |
| 昨日复盘 | 一句话，不展开，不自我攻击 | 建立连续反馈，但不用于自我PUA |
| 生活锚点 | 只记录运动、创造产出和消费边界 | 把原则变成行为，不增加14项打卡 |

## 填写示例

```markdown
## 日期：2024-03-18 星期一

### 昨晚睡眠：6.5小时（质量3）
（凌晨1点睡的，睡前刷了B站，下次手机要放远一点）

### 今日唯一目标（ONE Thing）：
实现登录页面的表单验证功能（邮箱格式+密码长度校验）

### 下一步行动（Next Action，必须具体）：
- [ ] 打开VS Code，进入 `src/components/Login.jsx`
- [ ] 添加邮箱正则判断：`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`
- [ ] 添加密码长度判断：密码长度≥6位
- [ ] 在表单提交时阻止默认行为，console.log验证结果
- [ ] 自己写满30分钟后，可以用AI优化代码，但必须逐行看懂

### 情绪状态（1-10）：
6
（周一有点焦虑，但目标很明确，做完第一步就会好）

### 昨日复盘（一句话）：
昨天实现了登录页面的静态布局，目标完成。卡在Flex布局的对齐方式上，花了太久查文档，今天遇到类似问题直接问AI先看懂再用。
```

## 使用规则

1. **填写时间**：前一晚睡前**或**当天早晨7:30前完成
2. **填写地点**：建议用手机/笔记本在床边或书桌前快速填写，不要开电脑（会分心）
3. **填写时长**：严格控制在3分钟以内，这不是写作文
4. **唯一目标必须来自你的进行中的项目**：不要写"学英语""看教程"这种伪目标，要写"完成XX功能的XX部分"

## 晨间日志与收件箱的关系

填写完晨间日志后，顺便做一件事：
- 快速扫一眼 `00-收件箱`
- 如果有与今日目标相关的内容，移入今天的项目文件夹
- 其余内容等晚上22:00统一处理

## 长期价值

连续填写30天后，你会拥有：
- 一条清晰的**情绪曲线**（发现自己哪几天状态最好）
- 一份诚实的**执行记录**（知道自己到底完成了多少目标）
- 一堆**下一步行动**的历史档案（发现自己总在什么类型的事情上卡住）

> 不要小看这3分钟。它是你每天对自己做出的第一个承诺。目标越清晰，你今天的决策负担就越轻。目标模糊，你一整天都在"找事做"——然后找到了B站和短视频。
