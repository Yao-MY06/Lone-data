## 看板模板

| 待启动（想法池） | 进行中（≤2） | 测试中（验收前） | 待变现（交付后） | 已完成（待归档） |
|:--|:--|:--|:--|:--|
| 项目想法和待启动项目 | 当前正在执行的项目（最多2个） | 已开发完、正在测试和修复的项目 | 已交付/上线，等待客户反馈或收入数据 | 已验收通过+变现闭环完成，等待2周后归档 |

## 各列说明与使用规则

| 列名 | 说明 | 最大数量 | 移动规则 |
|------|------|---------|---------|
| **待启动** | 已通过立项评估但尚未启动的项目 | 不限 | 从"下月预告"或新想法中移入 |
| **进行中** | 当前正在投入时间执行的项目 | **≤2个** | 每天早晨确认本周要推进的任务 |
| **测试中** | 核心功能开发完成，正在测试验收 | ≤1个 | 开发完成后移入，验收通过后移出 |
| **待变现** | 项目已交付/上线，等待收入确认或客户反馈 | ≤2个 | 验收通过后移入，收入确认或变现失败后移出 |
| **已完成** | 验收通过+变现闭环完成，处于2周缓冲期 | ≤3个 | 缓冲期满2周后移入 `Z-归档` |

### 新增"待变现"列说明

**为什么需要"待变现"？**

项目交付 ≠ 项目结束。从交付到收到钱（或确认无法变现）之间有一段"变现验证期"。这个列用来追踪：

- 客户项目：是否已收款？客户反馈如何？
- 求职项目：是否已投递？面试邀约了吗？
- 产品项目：是否已上线？有付费用户了吗？

**"待变现"列的退出条件：**

| 变现路径 | 退出标准（移入"已完成"） |
|----------|------------------------|
| 接单 | 客户确认验收 + 款项到账 |
| 求职 | 拿到offer或收到明确拒绝（积累面试经验） |
| 产品 | 有付费用户 或 上线30天后确认无需求 |
| 纯学习 | 项目验收通过即移入"已完成"（跳过待变现） |

## 项目卡片格式

每个项目卡片包含以下信息：

```markdown
**[项目名称]**
- 目标交付物：（一句话）
- 截止日期：YYYY-MM-DD
- 本周下一步：（具体的下一步行动）
- 风险点：（可能卡住的地方）
- 变现类型：商业项目/半商业项目/纯学习
- 变现三问答案：（谁需要/怎么解决/收多少钱）
- 收入状态：（待变现项目中填写：报价中/开发中/已交付/已收款）
```

## 每日看板Review流程（每天早晨2分钟）

```
打开项目看板
  ↓
看"进行中"列：确认今天的主要推进方向
  ↓
检查本周下一步行动是否需要更新（昨晚的进展）
  ↓
如果有项目卡在"进行中"超过1周没有进展：
  → 标记风险
  → 决定：继续推进 / 缩减范围 / 暂停
  ↓
关闭看板，开始执行
```

## 每周日看板更新流程（复盘时10分钟）

```
打开项目看板
  ↓
更新所有"进行中"项目的状态（本周完成了什么）
  ↓
如果有项目完成开发：
  → 移入"测试中"
  → 启动验收检查清单
  ↓
如果有项目通过验收：
  → 移入"已完成"
  → 开始2周缓冲期倒计时
  ↓
如果有"已完成"项目缓冲期满2周：
  → 移入 Z-归档
  ↓
如果有"待启动"项目且"进行中"有空位（<2个）：
  → 移入"进行中"
  → 拆解第一周任务
  ↓
确认下周的项目优先级
```

## 风险点标记规则

当项目出现以下情况时，在"风险点"中标记：

| 风险类型 | 标记 | 应对措施 |
|---------|------|---------|
| 进度滞后 | 🔴 滞后 | 缩减范围或暂停次要项目 |
| 技术卡点 | 🟡 技术风险 | 30分钟搞不定就问AI/查文档 |
| 时间不足 | 🟡 时间风险 | 检查是否有其他项目占用时间 |
| 动力下降 | 🟠 动力风险 | 回忆最初为什么立项，看已完成的部分 |

## 看板与PARA的关系

```
PARA框架：          看板映射：
02-项目管理/        → 看板中的"进行中"+"测试中"+"已完成"
  ├── [项目A]/      → 进行中（P0）
  ├── [项目B]/      → 进行中（P1）
  └── [项目C]/      → 测试中
01-日记与周期/      → 月度规划中的"下月预告" → 看板"待启动"
  └── 月度规划.md
```

> 看板是你每天看一次的全局视图。不要把它当成又一个需要维护的负担——它只需要每天早晨2分钟扫一眼，确保你清楚今天该推进什么。如果你连2分钟都不愿意花，那你对自己的项目也没有那么上心。
