## 早晨（起床后到上课前）

**核心原则：每天的第一件事必须是为自己的项目工作。**

```
1. 闹钟响 → 下床 → 洗漱（不看手机通知）
2. 到学习地点（图书馆/自习室）
3. 打开P0项目代码
4. 写30分钟（不用AI，可以查文档）
5. 休息5分钟
6. 再用AI辅助/调试/优化30分钟
7. Git提交 + Push（让绿墙多一格）
8. 去上课
```

**如果起晚了/时间不够**：只做步骤3-4，哪怕只写15分钟也要提交。

---

## 白天（上课时间）

```
□ 课间不刷B站/短视频
□ 有作业？先手写30分钟框架，再用AI
□ 没作业？看技术文章，有用的截图存到00-收件箱
```

---

## 晚上（19:00-22:00）

```
□ 19:00-20:00：继续推进P0项目（或补早晨没做完的）
□ 20:00-20:30：Git提交 + 写项目日志（1句话）
□ 21:45-22:00：打开"00-当前状态面板.md"，更新：
    - 今天完成了什么？（1句话）
    - 明天的"唯一目标"是什么？（具体到一个文件/函数）
    - 收件箱≤3条了吗？
```

---

## 睡前（2分钟）

```
□ 手机放远（必须下床才能拿到）
□ 定明天闹钟
□ 脑子里过一遍：明天第一件事是打开哪个文件？
```

## 三档模式速查

| 模式 | 做什么 | 不做什么 |
|------|--------|----------|
| **标准日**（正常） | 早晨1.5h + 晚间1h | 不加新任务 |
| **普通日**（课多） | 早晨30分钟P0 + 晚上更新面板 | 不焦虑没做满 |
| **崩盘日**（状态差） | 只写"明天唯一目标" + 早睡 | 不自责 |

---

## 遇到这些情况怎么办？

| 情况 | 对策 |
|------|------|
| 想玩游戏/刷B站 | 告诉自己："做完今天P0，22:00后可以玩1小时" |
| 想学新技能（Rust/Go/区块链…） | 写入00-收件箱，等P0完成后再评估 |
| P0卡住了 | 跳过这个难点，先做下一个功能，明天再回头 |
| 连续3天没推进P0 | 缩小范围：砍掉一半功能，先让最简版跑起来 |
| 不知道今天做什么 | 打开"00-当前状态面板.md"，看"下一步行动" |

---

## 一句话总结

> 每天只做四件事：推进P0、Git提交、更新面板、写明天目标。其他都是bonus。
