## 一、进入心流前的6步检查

每次坐下准备学习/编码前，花**60秒**完成以下检查：

- [ ] **1. 下一步行动已写好在便签/日志上（目标清晰）**
  - 打开晨间日志或项目看板
  - 确认接下来25分钟要做什么
  - 例："接下来25分钟：在TodoList.jsx中实现删除功能"
  - **模糊的目标 = 100%的拖延。具体的目标 = 50%的完成。**

- [ ] **2. 手机已放到需要走三步才能拿到的地方（干扰隔绝）**
  - 物理距离是最高效的屏蔽手段
  - 放在另一个房间、走廊尽头、柜子里
  - **飞行模式不够**，你会本能地打开看
  - 如果需要用手机的番茄钟App → 放在视线外但仍能听到提示音的地方

- [ ] **3. 电脑已屏蔽B站/游戏/社交网站（Cold Turkey已启动）**
  - 打开Cold Turkey/Focus/类似工具
  - 屏蔽列表：bilibili.com、weibo.com、twitter.com、steam、游戏启动器
  - **屏蔽时间至少设为2小时**（即使你只学1小时）
  - 如果Cold Turkey不可用 → 修改hosts文件（教程自行搜索）

- [ ] **4. 音乐已播放（同一首lofi/game ost循环）**
  - 打开YouTube/Spotify
  - 搜索 "lofi beats to study to" 或 "game OST study mix"
  - **同一首歌/同一个播放列表循环**，不要换歌（换歌=决策=分心）
  - 推荐：Chillhop Music、Sonic the Hedgehog OST、Stardew Valley OST
  - 音量：刚好能听到，但不干扰思考

- [ ] **5. 水杯已接满，厕所已去（生理需求解决）**
  - 站起身，去接一杯水
  - 去一趟厕所
  - **25分钟内不要给自己任何站起来的理由**
  - 水杯放在手边，不需要起身就能拿到

- [ ] **6. 计时器已设置（25分钟番茄钟）**
  - 打开番茄钟App或手机计时器
  - 设定25分钟
  - 点击开始
  - **计时器开始的那一刻，就是你承诺专注的时刻**

### 60秒快速版（熟练后可简化）

```
□ 下一步写好了？
□ 手机放远了？
□ Cold Turkey开了？
□ 音乐在播放？
□ 水杯满了？
□ 计时器设了25分钟？
→ GO
```

## 二、心流维持技巧

### 25分钟到后怎么办？

**规则：看状态，不强制。**

| 情况 | 行动 |
|------|------|
| 状态很好，不想停 | **继续。** 再设25分钟，不强制休息。打断心流比不休息危害更大。 |
| 状态一般，有点累 | 休息5分钟。走动、喝水、看窗外。不要碰手机。 |
| 状态很差，坐不住 | 休息10分钟。问自己：是身体累了还是任务太难了？如果是任务太难，把下一步拆解得更小。 |

### 思路中断时怎么办？

**无论中断来自外部（消息/噪音）还是内部（走神），统一流程：**

1. **立刻在日志上写一句"刚才做到哪了"**
   - 例："刚才在写handleDelete函数，传到第3个参数时被打断"
   - 这句话是你回来的锚点

2. **判断中断来源**
   - 外部噪音 → 戴上耳机/关窗户/换个位置
   - 消息通知 → 关闭通知源（飞行模式/关App）
   - 内行走神 → 在日志边缘写下走神的主题，告诉自己"稍后处理"，回到当前任务

3. **回到日志，读"刚才做到哪了"，继续**

### 连续番茄钟后的强制休息

**连续4个番茄钟（约2小时）后，必须休息15分钟。**

这不是建议，是强制规则。因为：
- 大脑在2小时后效率显著下降
- 久坐对身体有害
- 休息后的下一个番茄钟质量会高很多

**15分钟休息可以做什么：**
- ✅ 走动/爬楼梯
- ✅ 远眺窗外（保护视力）
- ✅ 做几个俯卧撑/深蹲
- ✅ 接水、上厕所
- ❌ 看手机（会陷入时间黑洞）
- ❌ 刷B站/社交媒体（会彻底打断心流）

## 三、心流崩溃后的恢复SOP

**如果你被打断了（无论是外部打断还是自己失控了），不要自责。按流程恢复。**

### Step 1：接受现实（30秒）

> "心流被打断了。这很正常。不是世界末日。我不需要自责。我需要做的是恢复。"

**不要做的事：**
- ❌ "我怎么又分心了"（自我攻击）
- ❌ "今天废了，明天再开始吧"（破罐破摔）
- ❌ "反正已经浪费1小时了，不如再玩一会儿"（滑坡谬误）

### Step 2：记录打断原因（30秒）

在日志上写：
```
[打断记录] 时间：XX:XX
原因：_________________
下次预防：_________________
```

示例：
```
[打断记录] 时间：15:30
原因：手机放在桌上，看到微信通知就点进去了
下次预防：学习时手机放另一个房间
```

### Step 3：判断当前状态（30秒）

| 状态 | 行动 |
|------|------|
| 还能继续学 | 重新走6步检查清单，设25分钟番茄钟，继续 |
| 很累/很烦躁 | 休息15分钟（走动/远眺），然后重新启动 |
| 完全不想学 | 问自己：是身体问题（饿/困）还是逃避？解决身体问题后重新启动 |

### Step 4：重新启动

按照"进入心流前的6步检查清单"重新走一遍，从头开始一个25分钟番茄钟。

**关键是：越小步启动越好。**
不要想"我还要学2小时"，想"我先学25分钟"。25分钟后的事25分钟后再说。

### 当天多次崩溃的应急方案

如果一天内心流崩溃了3次以上：

1. **问自己今天是否适合学习**
   - 身体状态不好（头痛/太困/生病）→ 休息，不勉强
   - 身体没问题但心理抗拒 → 可能是任务太大/太模糊，需要拆解

2. **缩小目标到最小可执行单元**
   - 不要"学完React Hooks" → 要"理解useState的语法"
   - 不要"做完登录功能" → 要"写一个验证邮箱格式的正则表达式"

3. **如果还是无法进入状态**
   - 允许当天暂停学习
   - 但有一个条件：在日志上写清楚**为什么今天不行**和**明天如何改进**
   - 这不是放弃，这是有记录的暂停

## 四、心流环境的长期建设

### 物理环境

- [ ] **固定学习位置**：总在同一个位置学习（同一张桌子/同一个座位）
- [ ] **桌面只放当前项目相关的东西**：其他物品收起来
- [ ] **屏幕只开需要的窗口**：其他应用最小化或关闭
- [ ] **背景噪音固定**：总是同一首歌或同一个播放列表

### 数字环境

- [ ] **浏览器只开一个项目相关的标签页**：其他全部关闭
- [ ] **VS Code只打开当前项目的文件夹**：不同时在多个项目间切换
- [ ] **Cold Turkey默认屏蔽列表已配置好**：不需要每次手动设置
- [ ] **桌面壁纸简洁**：不要花哨的动态壁纸

### 心理环境

- [ ] **晨间日志已写好今天的目标**：知道今天要做什么
- [ ] **下一步行动足够具体**：不是"学React"，是"在App.jsx中添加useState"
- [ ] **允许自己不完美**：心流不是"100%专注不中断"，是"即使中断了也能回来"
