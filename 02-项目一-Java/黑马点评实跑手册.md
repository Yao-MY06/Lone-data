# 黑马点评实跑手册（自己跑一遍 = 你的证据）

> 目的：把 2026-10-20 那轮"AI 代跑"的全部步骤，整理成**你自己能照着敲一遍**的流程。敲完这一遍，阶段门 ②–⑦ 就是你亲手跑出来的，不再算 AI 代跑。
> 预计耗时：**40–60 分钟**（不含环境问题排查）。

## 零、开始前必读

### 0.1 终端必须用 Git Bash，不要用 PowerShell

| 现象 | 原因 |
|---|---|
| 命令后面出现 `>>`，敲回车不执行 | PowerShell 的**续行提示符**，说明上一条命令没结束 |
| `The '<' operator is reserved for future use` | PowerShell **不支持 `<` 重定向** |
| `ping` 输出一堆 `-t -a -n count` 选项 | 你敲的是 Windows 的网络 ping，不是 Redis 的 `PING` |

→ 在开始菜单搜 `Git Bash`，用它。提示符是 `$` 结尾那种。

### 0.2 三个本机固定值（后面反复用到）

```bash
API=http://127.0.0.1:8081
MYSQL="/c/Program Files/MySQL/MySQL Server 9.5/bin/mysql"
LOG="F:/study/黑马点评/run.log"
```

### 0.3 每条 curl 都必须带 `--noproxy '*'`

本机设了 `HTTP_PROXY`，不带这个参数，localhost 请求会被代理接管 → 返回 502。**这是最容易让人以为"服务挂了"的坑。**

## 二、阶段门 ② — 登录 + 受保护接口

### 步骤 6：发验证码

```bash
PHONE=13700000001          # 用一个没注册过的号，每次跑换一个
curl -s --noproxy '*' -X POST "$API/user/code?phone=$PHONE"
```

**期望**：`{"success":true}`

### 步骤 7：从 Redis 取验证码

```bash
CODE=$(docker exec redis redis-cli -a 123321 get "login:code:$PHONE" | tr -d '\r')
echo "code=$CODE"
```

**期望**：6 位数字，例如 `code=482913`

> **这一步本身就是一个知识点**：验证码存在 `login:code:{手机号}` 里，TTL **只有 2 分钟**。这套 key 设计就是学习日 3 讲的"Session 换 Redis"。
> **不要去看日志**——日志是 GBK 编码，中文全是乱码，查 Redis 最干净。

### 步骤 8：登录拿 token

```bash
LOGIN=$(curl -s --noproxy '*' -X POST "$API/user/login" \
  -H "Content-Type: application/json" \
  -d "{\"phone\":\"$PHONE\",\"code\":\"$CODE\"}")
echo "$LOGIN"
TOKEN=$(echo "$LOGIN" | sed -n 's/.*"data":"\([^"]*\)".*/\1/p')
echo "token=$TOKEN"
```

**期望**：`{"success":true,"data":"一串32位十六进制"}`

### 步骤 9：三连验证（这一组才是阶段门 ② 的核心）

```bash
# ① 带 token → 应该 200 并返回用户信息
curl -s --noproxy '*' -H "authorization: $TOKEN" "$API/user/me"

# ② 不带 token → 应该 401
curl -s --noproxy '*' -o /dev/null -w "no-token HTTP %{http_code}\n" "$API/user/me"

# ③ 伪造 token → 应该 401
curl -s --noproxy '*' -o /dev/null -w "fake-token HTTP %{http_code}\n" \
  -H "authorization: fake-token-123" "$API/user/me"
```

**期望**：

```
{"success":true,"data":{"id":1017,"nickName":"user_xxxxxxxxxx","icon":""}}
no-token HTTP 401
fake-token HTTP 401
```

**把 `id` 记下来**，后面 Feed 要用：`echo $MYID`（手动填，例如 1017）

### 步骤 10：看 Redis 里的登录凭证

```bash
docker exec redis redis-cli -a 123321 hgetall "login:token:$TOKEN"
docker exec redis redis-cli -a 123321 ttl "login:token:$TOKEN"
```

**期望**：Hash 三个字段 `id` / `nickName` / `icon`；TTL 约 **2159900+ 秒**（= 25 天）

> ✅ **② 判定标准**：带 token 返回用户 JSON、不带/伪造都 401、Redis 里有对应 Hash —— 三条齐了就算过。

## 三、阶段门 ③ — 缓存 miss / hit 可区分

### 步骤 11：清缓存，制造一次 miss

```bash
docker exec redis redis-cli -a 123321 del cache:shop:1
BEFORE=$(grep -ac "ShopMapper.selectById" "$LOG")
curl -s --noproxy '*' "$API/shop/1" | head -c 120; echo
sleep 1
MID=$(grep -ac "ShopMapper.selectById" "$LOG")
echo "miss 后 SQL 次数：$BEFORE -> $MID"
```

**期望**：返回「103茶餐厅」的 JSON；SQL 次数**增加了 3**（MyBatis 一次查询打 3 行日志）。

### 步骤 12：再请求一次，制造 hit

```bash
curl -s --noproxy '*' "$API/shop/1" | head -c 120; echo
sleep 1
AFTER=$(grep -ac "ShopMapper.selectById" "$LOG")
echo "hit 后 SQL 次数：$MID -> $AFTER"
```

**期望**：SQL 次数**完全不变**（`$MID` == `$AFTER`）。这就是"命中缓存不查库"的硬证据。

### 步骤 13：日志三段对照

```bash
iconv -f GBK -t UTF-8 "$LOG" 2>/dev/null | grep -E "缓存未命中|写回缓存|缓存命中" | tail -3
```

**期望**：

```
【缓存未命中】shopId=1，查询数据库
【写回缓存】shopId=1，TTL=30分钟
【缓存命中】shopId=1
```

### 步骤 14：顺手验证缓存穿透防护

```bash
curl -s --noproxy '*' "$API/shop/999999"; echo
docker exec redis redis-cli -a 123321 get "cache:shop:999999"
docker exec redis redis-cli -a 123321 ttl "cache:shop:999999"
```

**期望**：`店铺不存在！`；Redis 里存了一个**空值**，TTL 约 **120 秒**（2 分钟）—— 这是"缓存空对象"防穿透。

> ✅ **③ 判定标准**：清缓存后 SQL 次数 +3、再请求不变、日志三段可区分 —— 三条齐了就算过。

【秒杀成功】orderId=6507... user=1017 voucherId=2
【秒杀】user=1017 释放锁（Lua）

### 6.3 签到（BitMap）

```bash
# ① 签到前的连续天数
curl -s --noproxy '*' -H "authorization: $TOKEN2" "$API/user/sign/count"; echo

# ② 签到
curl -s --noproxy '*' -X PUT -H "authorization: $TOKEN2" "$API/user/sign"; echo

# ③ 签到后的连续天数
curl -s --noproxy '*' -H "authorization: $TOKEN2" "$API/user/sign/count"; echo

# ④ 看位图本体
KEY="sign:$UID2:$(date +%Y%m)"
docker exec redis redis-cli -a 123321 get "$KEY"
echo "今天是 $(date +%d) 号，第 $(( $(date +%d) - 1 )) 位应该为 1："
docker exec redis redis-cli -a 123321 getbit "$KEY" $(( $(date +%d) - 1 ))
echo "BITFIELD GET u$(date +%d) 0 的返回："
docker exec redis redis-cli -a 123321 bitfield "$KEY" get "u$(date +%d)" 0
```

**期望**：签到前 `0`、签到后 `1`（第一次跑）；`getbit` 返回 `1`；`BITFIELD` 返回一个整数（例如今天是 20 号、只有今天签到 → 返回 `1`）。

**想验证"连续 3 天"**（造前两天的位）：

```bash
D=$(date +%d)
docker exec redis redis-cli -a 123321 setbit "$KEY" $((D-3)) 1 >/dev/null   # 前天
docker exec redis redis-cli -a 123321 setbit "$KEY" $((D-2)) 1 >/dev/null   # 昨天
curl -s --noproxy '*' -H "authorization: $TOKEN2" "$API/user/sign/count"; echo
```

**期望**：`{"success":true,"data":3}`

## 九、卡住了怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| `Cannot connect to the Docker daemon` | Docker Desktop 没起 | 手动双击图标，等稳定 |
| `NOAUTH Authentication required` | 没带密码 | `-a 123321` |
| 应用起在 58216 / `PortInUseException` | `SERVER__PORT` 注入 | `env -u SERVER__PORT -u SERVER_PORT -u SERVER__HOST` |
| `curl` 返回 502 / 空 | `HTTP_PROXY` 接管了 localhost | 每条 curl 加 `--noproxy '*'` |
| `The '<' operator is reserved` | 在 PowerShell 里 | 换 Git Bash |
| `ERR value is not a valid float`（灌 GEO 时） | CRLF 带 `\r` | 管道加 `tr -d '\r'` |
| 日志里中文全是乱码 | 控制台 GBK | `iconv -f GBK -t UTF-8 run.log` |
| `验证码错误` | 码过期了（**只有 2 分钟**） | 重新发码，立刻取 |
| `feed:{id}` 是空的 | 先发笔记后关注了 | 顺序改成**先关注，再发笔记** |
| `mvn clean` 失败 | IDE 语言服务器锁 `target` | 用 `mvn package`，别 clean |
